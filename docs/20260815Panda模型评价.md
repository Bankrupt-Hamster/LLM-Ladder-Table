# 使用途径

## 免费版/网页对话

几乎所有模型厂在官网都提供免费的网页对话服务，但*所有*网页对话服务都可能被
1. 限制参数：例如输出限制到32K（尽管完整API是384K）——各家基本都有 思考强度effort限制为low等低档位——各家基本都有 输出截断——各家基本都有 周期使用量限制等——字节的豆包，GPT的路由至小模型应该也算
2. 限制模型：包括但不限于仅提供部分模型，不提供旗舰模型(字节的豆包，GLM，KIMI，Qwen) 悄悄路由至小模型（GPT,Gemini等国外模型厂喜欢干这个）
因此网页端对话对生产用途而言远远不够，何况免费的API其实并不难以获取

这里特别说一下的是豆包，它的app提供2个模型：doubao2.0fast（默认）和doubao2.1turbo（思考），默认模型几乎不可用，起码处于12~18个月前的水平，它不但快而且快。思考模型可堪一用但沟槽的豆包居然给这玩意弄了周限额

## API使用

有一定AI需求的人群几乎一定会使用现在的类Harness产品，这就需要使用模型的API接入,主要有以下获取途径：

1. 国内模型

国内模型一般都设有比较简单的API使用途径，可以在官网找到，除了有大厂毛病的字节和千问的官网，其他的官网获取API都比较容易直接，这里说一下字节和千问。

字节：登录https://www.volcengine.com/ 火山方舟平台 -> 控制台 -> 获取API

千问：登录https://bailian.console.aliyun.com/cn-beijing 阿里云百炼控制台 -> 获取API

2. 国外模型

列出的国外模型都能轻松的在官网的开发者平台获取API，但注意OpenAI与Anthropic这两个公司会要求提供国外的手机号接码

3. Harness提供

现在很多Harness内都会提供一些大模型接入，我们分为各公司的Harness产品和第三方Harness产品

各公司的Harness产品一般有两种：1. 接入模型的API使用 2. 提供单独的积分制度，可以随意使用提供的产品

而第三方Harness产品与上述提到的2类似，只不过它们通常提供多家模型产品，选择广一些

诸如腾讯的WorkBuddy，字节的Trae系列，OpenCode，Cline，Cursor等

值得注意的是大多数第三方Harness产品都提供一些免费的模型供使用，例如Trae的部分模型（比如它自家的Doubao-Seed），WorkBuddy的Hy3，OpenCodeZen，Cline提供GLM5.2等等

对于轻度使用来说，这些免费模型已经足够了，它们通常性能较低/阉割上下文参数思考强度等（OpenCodeZen限制128K上下文）

4. 第三方中转站

所有中转站都有风险！！！永远不要用国内的野鸡中转站，可以上国外的OpenRounter看看。但肯定是存在数据泄露的风险，而且这上面正规的中转通常也不怎么便宜，正规中转站掺水比较少，但是还是不可靠。而国内中转站全视为转接豆包赚傻逼钱

5. 订阅Coding Plan 与 广义的订阅Coding Plan

几乎所有公司都提供Coding Plan，这里说下我对各家Coding Plan的看法

1. Minimax 曾经量大管饱且通用多模态，可惜性能太低还迟迟不更新，现在已经落伍沦为路边一条，除非有大量的多模态需求（竞争位还有小米Mimo，QwenPlus等等），几乎不推荐购买。

2. Qwen 量太少，自家模型又是烧token大户，性价比不高，不建议购买

3. GLM 低档位抢不到也不够用，高档位太贵。而在20260731宣布涨价后，虽然放开了能拿到，但是问题依旧——低档位不够用，价格还翻了近三倍，不是很建议购买原厂，作为开源模型，许多第三方提供且可以在对应的订阅中使用

4. Kimi 低档位量太少，死贵，还有个值得注意的逆天点——买code套餐只能在harness中使用，买网页只能在官网使用。同样不建议购买原厂，许多第三方提供且可以在对应的订阅中使用

5. OpenAI Go量不够用，但论性价比是可以的，Plus是甜点区，高强度使用足够且价格合适，Pro对重度用户也算合适。总结比较推荐购买，特别是Plus。其他因素来讲，OpenAI几乎不封号（但是注意IP不干净可能路由到小模型），稳定，性能强，多模态支持，泛用性强，而且经常重置额度，是最推荐的方案之一。唯一一点吐槽是GPT5.6sol的烧的太快了，旗舰模型定价越来越高

6. Anthropic较贵，额度相对来说由于模型定价高，没有OpenAI耐用，编程与设计Harness产品很成熟，模型性能强。但是，极其！极其！极其不推荐购买，重置少，极其极其容易封号，经常干各种逆天事，偷偷路由小模型，下毒，是A\

7. Gemini人称哈基米，模型的世界库知识很强，擅长写文章，但逻辑一塌糊涂。由于谷歌各种奇怪政策和优惠导致搞一些低价套餐号很容易，基本都是找渠道买这种或第三方中转。原厂不建议

8. xAi/Cursor随着小马哥的收购，用grok主要通过Cursor，grok4.6~4.7据说不错，我还没用过，Cursor的订阅范围也比较广，综合来说我觉得还可以接受

广义的订阅Coding Plan 指所有月付用模型的渠道

1. OpenCodeGo/Cline/Cursor后两个我就不说了差不多的，OpenCodeGo使用的模型数量极其广且更新很快，但优惠力度有限且速度会较原厂明显低。由于一个邮箱就是一个新号所以首次开通5美元优惠几乎永续。但是经过202607的一波修改，大部分顶尖开源模型都变成了5美元买15美元且体验有所下降，对于Kimi k3这种可能跑不了啥就得歇菜。而对于部分保持5美元买60美元的模型，特别是DeepSeek Flash除了速度较慢且缓存命中不如官方渠道外几乎无限用。对有频繁AI需求且主力不是*Agent*编程的人群来说极其划算。

2. Trae是垃圾中的垃圾，谁买我笑他一辈子，幽默50块钱一个月用99次模型，一轮回话可能就要用20~30次，逆天完了

3. WorkBuddy幽默套餐定价，谁教你的免费版500，70一个月才2000，140一个月4000，不推荐购买

# Harness评价

这里指广义上的Harness，只要存在Agent loop，无论交互方式都算。我用过的Harness有限，只评价我用过的，逐渐更新，按使用顺序

1. Trae
最早我在202509开始使用的，该有的基本都有，不知道是没什么前沿与理想还是懒总之落后别人一个身位，现在估计落后的更多了。Harness性能较差，会明显降低模型的能力。交互界面极其友好，支持从VScode迁移，很方便。早期模型支持很舒服，国内大量模型免费使用不排队，后面开始逆天定价到处排队。这个排队机制绝对不是真的有人在排队，一个半年前先进标识要排队的模型你半年后了也不改，一用无论时段稳定给你排几百+，固然有一些真正的前沿模型是在排队呈现明显的工作日-早晚变化，但也绝对有故意定一个时间恶心用户的现象存在。评价给到拉完了。

2. Cursor
不适合在国内用，用起来还是有点肉疼的，好用，最早的vibe领军者，现在的技术也还可以，但在国内用终究还是不方便。

3. WorkBuddy
今年3月浅尝了一下，感觉还是腾讯系产品的那种臃肿之后就没用了。7月又用了下发现关掉一些有的没的意外的好用，接上联网功能豆包限额了就当豆包用。1. 太笨重，加了很多没用的东西，但相对应的生态也比较全，省事。比如不用去装pptx skill就直接能处理，市场啥的都预装好了（虽然很多都没有）。 2. 喜欢加一些自以为聪明的插件，拖累agent能力，给ai个人定位记忆，还想搞情感伴侣，好几层记忆机制，还封闭不好diy，弄的ai老是把精力去给情绪价值、可视化展示画图（妈了个逼的任务才5分钟，画图，失败，调试了踏马15分钟，展示推送）。 3. 模型又新又不搞虚的（暂时），定价不高，送很多额度，嫖的很爽，这里用k3才1.62的倍率，一轮开max大概才50~150积分，蹬的很爽。而且有免费的hy3模型当豆包用，可惜速度不太行。弄一个号池大概4~5个号，一个月能有4000左右积分白嫖，很舒服。

4. OpenCode
今年早些时候浅尝了一下，为了支持所有模型感觉对每个模型适配都没有做的很好。agent能力较弱。

5. ClaudeCode
用的比较久，各种插件skill还有mcp，hook机制都很成熟。工具能力强大，文件管理稳健。问题有三个：1.隐藏思维过程，这对于把握AI的方向来说是个重大问题 2. 太重，各种提示词塞的太多了，可能导致ai能力的弱化和更多上下文占用，导致成本上涨 3. 没有简单的会话管理机制，删会话麻烦。现在还有对其他模型缓存适配不佳，下毒等问题，但仍属agent能力最强的一档。

6. Reasonix
早期是一个高度可自定义的薄Harness我很喜欢，做一些轻任务/编程无关任务效果很好，特别是堆DeepSeek缓存机制的适配。可惜后面作者魔了，一方面经常大改框架，另一方面喜欢堆各种特性功能，而且喜欢直接弄到发行版导致不稳定，部分反人类的，真正制约agent性能的问题没修，还看未来，得继续观察。我已经很久没更新版本了，写这个的时候最新版本是1.25.2不知道是否稳定，一个确定比较稳定的版本是1.15.0。

7. DeepSeek Harness
还没开始体验，但插件化的思想我一般认可。而把工具编程语言化，让模型可以一轮执行多次调用我非常！非常想要，而且质疑为啥别的agent不这么做。这是极好的想法。反馈说目前bug还很多，等稳定了再体验。

我个人现在主要接各种TUI和CLI接进vscode的终端或侧边栏内使用

# 模型评价

我使用的模型有限，仅会重点评价我使用过的模型或提一嘴我对见过的模型的印象，逐渐更新

## MiniMax

主要做轻小多模态模型赛道，自从2604开始打不过ds flash除了原生多模态已经没啥存在的必要了，MiniMax H3挺惊艳的，但不是主流领域

## Qwen

用得不多，曾经用过的几个模型都给我高分低能的感觉，回回都是跑分很高实际使用感觉和能力都一般，配不上同分数段的其他模型。喜欢雷霆大思考。但是它的小尺寸模型特别是Plus档的27-36B模型相当惊艳，不但具有多模态且具有大尺寸模型80%的性能。很有潜力，但是小模型能力低就是不好用，完不成任务就是完不成。

## GLM

以前没关注过，GLM5出来后才关注，GLM5同期感觉比DeepSeek稍强，很顺手，后面无论是GLM5.1还是GLM5.2，都感觉压DeepSeek一头，但是能力也没有跨代的提升，做不出来的问题还是做不出来，还贵了数倍。喜欢长考，特别是GLM5.2，从长考的思维链智商来看其实也不咋地，效果我也没觉得比DS4pro强多少。GLM5.3从跑分上来说很惊艳，还没用过。对智谱我的评价是真是后训练仙人，一个底模后训练竟然还能榨出这么强的潜力，而且这才744B，它这个后训练本事带给别人或者它什么时候重新训个底模真逆天了。

## Kimi

最早和豆包文心时代开始用，早期就是垃圾国模水平，直到r1开源思维链配合重训练的k2底座才赶上国模第一梯队。早期给我的印象就是逆天雷霆大思考，蒸太多蒸出逆天幻觉，那天我让他思考下我这个verilog代码为啥出问题，把波形图给他分析，他踏马思考5分钟后思维链跳到啥俄罗斯黑客网络劫持攻击了给我笑的。但是k3一扫我的刻板印象，重振荣光真是。一开始说跑分是次fable级的我还不信，结果用了下，喜欢雷霆大思考，喜欢开局思考20分钟起手，但是智商和细节都极其高，没有明显的过拟合感觉。思考推理一般，只不过因为大模型的智商和直觉，往往都能从容地完成推理。确实是次fable级的模型，很期待3.1或其他更经济的型号。k3还是太太太太贵了，输出价格能涨到100块还是太\了。

## DeepSeek

人民用的起的AI，关注度自然最高。

从活人感来说DeepSeek R1是后训练得最充分的，后面的自己都不能赶上，但DeepSeek系列活人感强一直是优良传统

另一个方面来说DeepSeek的纯智力而非跑分感觉是比较真实的，反映在逻辑，推理，数学上泛化性能强一些，与很多专注code刷分的模型不同，我目前只感觉DeepSeek与GPT有这个特质。

我从DeepSeek V3/R1时代开始关注该系列模型，第二个版本DeepSeek 0324短短2个月竟然比思考过的R1还强让我深感震撼，DeepSeek 0528开始则让我感觉它的思维链越来越模拟，对齐不充分经常导致语言混杂，稳定性不佳容易发癫，这个问题在V3后期版本很明显。DeepSeek 3.1提升是有的，但是思维链太啰嗦了，DeepSeek 3.2 Exp版本让我感觉甚至性能倒退了而且高度不稳定。最后的DeepSeek 3.2稳定版其实一定程度改善了思维链对齐问题，算是一个不错的版本。

DeepSeek V4刚出来的时候感到明显的提升，但感觉就差那一脚——后训练。经常有不听话，不听指令，注意力涣散的情况发生，且解决问题也不太稳定。

DeepSeek V4 Flash 0731 是我目前觉得极其甜点的优秀模型，快且智商足够，听指令，能很好地以我人机协作的方式推进任务，但模型尺寸小，直觉差，精度低的问题是存在的。

DeepSeek V4 Pro 0813 问题很大，能力确实有所提升但是幅度又不够大，但使用体验来说真的是倒退了。1. 喜欢雷霆大思考，动不动先思考个十几分钟不动手 2. 喜欢自己独立做事，不喜欢协作，不习惯寻求帮助，反馈情况，交互。 3. 偶发不稳定现象

涨价后真的是梁子了，flash能用，大概涨2.5倍，pro逆天了缓存命中价格涨了6~12倍，轰轰烈烈的token大降价结束了

## OpenAI

泛化的推理、逻辑、数学能力很强，有真智力感，但是很死板，没有活人感。

只用过GPT5.4,5.5和5.6sol，首先知识库跟国模不太一样，确实强一些，特别是有关于科研和研究知识领域。5.5执行效率和智商都很高，是我心中很平衡的版本，纯粹的强大。而5.6出来后偶然试过一下，雷霆大思考，烧的太快了太贵了，那个任务不能看出什么智力，不过自然是完成了，我使用的不多，不能下定论。

## Anthropic

一直听说很强，Fable让人感觉是下一个时代的模型，永远有人说比肩Fable，这就证明了其含金量，暂无实际使用体验

## Grok

以前听说很区，据说小马哥收购Cursor后4.5和4.6进步很明显，暂无实际使用体验

## Gemini

2.5pro是辉煌，后面一直是区，北美小豆包这一块，除了快而且快。但谷歌系的模型对话体验一直挺好的，除了最近蠢得发瘟让人不适那段时间
