- 本天梯榜是个人娱乐项目，无法与专业评测相比，不能很好的实际代表模型的水平，切勿当真

- 本天梯使用的评测榜单包括HLE，AA，DeepSWE，致知个人榜单

- AA榜单使用的是经原始数据集改良后的AA榜单，主要剔除了不合理的幻觉率惩罚措施，因为幻觉率让模型拒绝回答都能得分，我认为这不是一个很好的测试幻觉率的办法
- 剔除的思路借鉴知乎的https://www.zhihu.com/people/chegva和https://www.zhihu.com/people/tabnahida两位大佬的文章https://zhuanlan.zhihu.com/p/2032797597627311070与https://www.zhihu.com/question/2043503794751791638/answer/2043975770092089351
- 剔除幻觉后的榜单与我日常体验相符，因此我认为这是一个很好的方法，感谢大佬分享思路

- 致知个人榜单是 知乎的toyama nao大佬制作 个人主页https://www.zhihu.com/people/toyama 榜单地址https://llm2014.github.io/llm_benchmark/
- 他的个人榜单与个人使用体感吻合度很好，也符合我的使用体验，因此我认为其可信度很高，感谢大佬的分享

- 本榜单主要追踪202507-202608的模型，也有少量之前的模型，由于测评集的变化，为了将老模型对齐到这个天梯图，使用了多维KNN+线性插值的近似方法，新模型的可信度还不错，老模型看个乐呵，特别是202601之前的模型

- 模型分数越高，提升每一分实际提升的智能水平越高。我认为对大模型来说，智能水平的提高是很明显，易感知的，很多问题都有一个复杂度阈值，如果这个阈值超过了大模型的智能水平，那即便给予它充足的引导和思考预算也难以解决问题。为了在榜单上凸显这一点，我尝试将它们打散，使用的方法是很简单的斜率线性映射，随着模型原始分数的提高，每一分获得的最终分数收益k会随之提高，从效果上看我认为比较理想。寻找这个映射的几种尝试参见 天梯图\docs\分数折算参数曲线对比图.png
